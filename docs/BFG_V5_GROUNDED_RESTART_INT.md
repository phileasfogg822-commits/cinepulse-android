# The BFG 2016 — V5 source-grounded restart (INT pilot)
This is an **isolated read-only implementation**, not a movie restart. Its original INT project is `796b9f28-9f31-484f-91e2-e40a385950c6`. It contains accepted English/Urdu scene decisions. Do not delete, reset, or alter it.
The original *full 1,239-cue source SRT*, not just dry-run reports or a design PDF, must be supplied before a real new project can be created and independently checked.

Order: (1) intake SHA/cue times, (2) digest beats with exact cue IDs and quotes and verified video-only moments, (3) whole-film scene blueprint, (4) English and Urdu narration units linked by beat ID, (5) pre-TTS dry run, (6) remote TTS and measured SRTs preserving actual timings, (7) semantic groups for short sentences, (8) global source allocation and independently reviewed 9/10 visual scene suitability, (9) staged five-cue apply, (10) final cut-plan/full coverage and Windows export.

The prototype rejects unsupported digest citations, unverified visual events, missing SRT cues, weak 0.60 scene scores, and overlapping source intervals within one language. An SRT gap is **not proof** that there are dinosaurs or any other action. Real frames/video and a trustworthy verification process are necessary.

A full movie source is not yet present in this session; the CLI at `tools/bfg-grounded-intake.mjs` can generate an integrity receipt when the file is provided. No user tokens, secrets, Cloudflare deployments, D1 writes, Muse movie claims, or accepted V5 checkpoints are used.
